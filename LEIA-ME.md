# EntreNós — como subir pelo celular

Todos os arquivos ficam soltos, sem pastas.

1. No repositório do GitHub: botão "…" ao lado de **Code** → **Upload files**.
   Envie TODOS os arquivos deste zip, menos o `dados.yml`, e toque em **Commit changes**.
   (Os arquivos com o mesmo nome são substituídos.)

2. Botão "…" → **Create new file**.
   Nome: `.github/workflows/dados.yml`
   Conteúdo: copie o que está dentro do arquivo `dados.yml` deste zip.
   Toque em **Commit changes**.

3. Pronto. A busca dos números começa sozinha (veja em github.com/SEU-USUARIO/SEU-REPOSITORIO/actions).
   Depois roda todo dia e sempre que você enviar algo.

Para instalar como app no celular: abra o site no Chrome → menu ⋮ → **Adicionar à tela inicial** (ou **Instalar app**).
